# Unit Converter (Android)

A simple Android app I made while learning Android development with Java. It has three little converters (inches ↔ centimetres, centimetres ↔ metres and yards ↔ metres), a button to swap the direction of each one, and a help screen.

**Please note:** this isn't a real app and it's not meant to be published or used day to day. It's just a practice project for learning: activities, layouts for portrait and landscape, click listeners, custom exceptions and saving state when the screen rotates.

## Running it

Open the project in Android Studio and run it on an emulator or a device. The `activ1`–`activ5` and `guided` branches hold the earlier steps of the exercise; `master` has the final version.
